Profil Lengkap

SMP Negeri 156 Jakarta

Mengenal sejarah, visi, misi, dan komitmen pelayanan pendidikan masyarakat Johar Baru, Jakarta Pusat.

Sejarah Singkat

SMP Negeri 156 Jakarta (NPSN: 20100230) berdiri sebagai salah satu sarana pendidikan menengah pertama utama di wilayah Kelurahan Johar Baru, Kecamatan Johar Baru, Jakarta Pusat.

Berlokasi di Jalan Kramat Pulo Gundul III, sekolah ini secara konsisten mengembangkan potensi peserta didik melalui pembelajaran terpadu, pembiasaan religius, fasilitas laboratorium komputer, perpustakaan, serta program keunggulan Sekolah Berbudaya Lingkungan (Adiwiyata) dengan sarana Green House dan pengolahan sampah mandiri.

Pembelajaran berbasis lingkungan dan teknologi di SMPN 156 Jakarta.

Visi Sekolah

"Terwujudnya Lulusan yang Berakhlak Mulia, Cerdas, Berprestasi, Berwawasan Lingkungan Hidup, dan Siap Menghadapi Perkembangan Era Digital."

Misi Sekolah

  • Menumbuhkan kedisiplinan dan pembiasaan nilai-nilai keagamaan.
  • Menyelenggarakan pembelajaran berbasis ICT yang inovatif dan interaktif.
  • Mengembangkan potensi bakat siswa melalui kegiatan ekstrakurikuler.
  • Mewujudkan lingkungan sekolah yang bersih, asri, dan hijau (Adiwiyata).

Pemprov DKI Jakarta

Kartu Jakarta Pintar (KJP Plus)

Bantuan biaya pendidikan dari Pemprov DKI Jakarta bagi siswa usia sekolah dari keluarga tidak mampu.

Persyaratan Utama:

  • Terdaftar dalam Data Terpadu Kesejahteraan Sosial (DTKS).
  • Memiliki NIK DKI Jakarta dan berdomisili di DKI Jakarta.
  • Mempunyai tata tertib disiplin sekolah yang baik.
Kemendikbudristek RI

Program Indonesia Pintar (PIP)

Bantuan tunai dari pemerintah pusat bagi peserta didik pemegang Kartu Indonesia Pintar (KIP).

Persyaratan Utama:

  • Peserta didik pemegang KIP / KKS / PKH.
  • Terdaftar dan aktif pada aplikasi Dapodik sekolah.
  • Diusulkan melalui dinas pendidikan setempat.

Panduan Admin: Kode Google Apps Script Auto-Header Spreadsheet

Tempelkan kode Apps Script berikut ke Google Sheets Anda (`Extensions > Apps Script`). Script ini **otomatis membuat Sheet 'Pesan Kontak' dan menambahkan Header baris pertama** jika sheet belum dibuat saat pertama kali menerima kiriman form.

function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.tryLock(10000);
  
  try {
    var doc = SpreadsheetApp.getActiveSpreadsheet();
    var sheetName = "Pesan Kontak";
    var sheet = doc.getSheetByName(sheetName);
    
    // Auto-create Sheet & Headers if missing
    if (!sheet) {
      sheet = doc.insertSheet(sheetName);
      var headers = ["Waktu Kirim", "Nama Lengkap", "Email", "No. WhatsApp", "Kategori", "Pesan", "Status"];
      sheet.appendRow(headers);
      
      var headerRange = sheet.getRange(1, 1, 1, headers.length);
      headerRange.setFontWeight("bold");
      headerRange.setBackground("#1E3A8A");
      headerRange.setFontColor("#FFFFFF");
      sheet.setFrozenRows(1);
    }
    
    var data = JSON.parse(e.postData.contents);
    var timestamp = new Date().toLocaleString("id-ID", { timeZone: "Asia/Jakarta" });
    
    sheet.appendRow([
      timestamp,
      data.nama || "-",
      data.email || "-",
      data.whatsapp || "-",
      data.kategori || "-",
      data.pesan || "-",
      "Belum Dibaca"
    ]);
    
    return ContentService
      .createTextOutput(JSON.stringify({ "result": "success" }))
      .setMimeType(ContentService.MimeType.JSON);
      
  } catch (error) {
    return ContentService
      .createTextOutput(JSON.stringify({ "result": "error", "error": error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  } finally {
    lock.releaseLock();
  }
}
